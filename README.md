# RevivePay AI

> **SIMULATED DATA — Not connected to any live payment system.**
> All payment effects in this repository are simulated.

An autonomous revenue-recovery control plane for payments companies — built to detect
at-risk revenue, reason about interventions, enforce financial-safety constraints, and
prove its results through rigorous counterfactual evaluation.

### Quick Start

```bash
git clone <repo-url>
cd revivepay-ai
cp .env.example .env   # edit as needed; no real keys required for demo
make setup             # install backend + frontend dependencies
make seed              # generate synthetic data
make demo              # run the full demo
```
